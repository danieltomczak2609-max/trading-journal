# Trading Journal

Persönliches Trading-Journal mit Live-Sync aus MetaTrader 5. Die App läuft auf dem Mac und dem iPhone.

- **App:** https://danieltomczak2609-max.github.io/trading-journal/
- **Daten:** liegen in Supabase und sind durch Login und Zugriffsschutz pro Nutzer geschützt. Dieses Repository enthält nur den App-Code. Der Schlüssel in `config.js` ist der öffentliche „Publishable Key“ und darf hier stehen.
- **Backup und Notfallplan:** im privaten Repository `trading-journal-backup`.

Für ein Update der App werden die geänderten Dateien hier hochgeladen. GitHub Pages veröffentlicht sie nach ca. 1 Minute automatisch.
